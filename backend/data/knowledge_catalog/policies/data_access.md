# Data Access Policy

## Principle

Access should be limited to the minimum datasets and fields required for an approved learning or
analytics purpose. Aggregate results are preferred when row-level detail is unnecessary.

## Controls

Use read-only analytical credentials, record approval through the local governance process, and
review continued need periodically. This learning policy does not grant production access.
